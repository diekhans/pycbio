Search:
  • What is typed is a case-insensitive regular expression, matched anywhere in the value: ^chr1$ matches only the whole value, MIR1|MIR2 either of two.
  • To match everything but some value, negate it with a look-ahead: ^(?!ok$).* finds all values other than ok.
  • The box under a column name filters on that column alone.
  • The Search box matches against all columns at once.
  • Filters combine: a row is shown only when it passes every one of them.
  • An expression that is not valid, as while it is still being typed, matches as plain text instead.
